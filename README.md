# Escritor Livre — Site Oficial de Robério Diógenes

Site pessoal do escritor independente Robério Diógenes.

## Estrutura do Projeto

```
escritorlivre/
├── index.html          ← Página principal (concluída)
├── livros.html         ← Biblioteca de livros
├── autor.html          ← Biografia + contato + redes sociais
├── blog.html           ← O Diário de um Escritor
├── contato.html        ← Formulário de contato
├── modelo.html         ← Template base para novas páginas
├── 404.html            ← Página de erro personalizada
├── README.md
│
├── css/
│   ├── variables.css   ← PALETA DE CORES — edite aqui para mudar o tema
│   ├── global.css      ← Estilos globais (nav, footer, botões)
│   └── [pagina].css    ← Estilos específicos por página
│
├── js/
│   ├── main.js         ← Scripts globais (cursor, nav, scroll reveal)
│   └── [pagina].js     ← Scripts específicos por página
│
├── img/                ← Imagens gerais
│
├── blog/               ← Arquivos HTML dos posts do blog
│   └── post-01.html
│
└── livros/             ← Páginas individuais dos livros
    ├── jogo-das-mascaras.html
    ├── a-setima-lei.html
    └── ...
```

## Tema Visual: "Tinta & Bruma"

Paleta baseada em pergaminho escuro (#110e0a), ouro envelhecido (#c9a84c) e bordô dramático (#7a2030). Para alterar qualquer cor, edite apenas `css/variables.css`.

## Fontes Utilizadas (Google Fonts)

- **Cinzel Decorative** — Logo e ornamentos
- **Playfair Display** — Títulos
- **Lora** — Corpo de texto
- **Cormorant Garamond** — UI e labels
